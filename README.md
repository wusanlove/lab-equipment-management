# 实验室设备管理系统（软件工程团队项目）

高校实验室设备与耗材管理系统。覆盖设备从采购入库、借用归还、维修报废到库存统计的完整流程，并对试剂耗材做低库存预警。

> 课程项目：三峡大学《软件工程》团队项目（第 01 组）

## 一、项目做了什么

实验室的设备和耗材，过去多靠 Excel 加纸质本子登记：谁借走了、坏了有没有修、库存还剩多少，查起来很麻烦，还容易记漏。本系统把这条线统一管理起来，并按角色区分能做什么。

## 二、七个功能模块

| 模块 | 主要功能 | 主要使用者 |
| --- | --- | --- |
| 安全与权限 | 注册登录、四角色权限控制、操作日志 | 全部 |
| 设备信息 | 设备建档、按状态/库位/类别查询 | 实验室管理员 |
| 设备采购 | 提交采购申请 → 审批 → 到货自动建档入库 | 教师、管理员 |
| 设备使用 | 借用申请 → 审批 → 归还验收（完好/损坏分开处理） | 师生、管理员 |
| 维修与报废 | 故障报修、维修完工、报废审批 | 管理员 |
| 仓库库存 | 在库/借出/维修/报废数量统计与完好率 | 管理员 |
| 物资耗材 | 入库、领用出库、低于安全库存自动预警 | 教师、管理员 |

## 三、两个实现上的要点

1. **设备状态机**：设备只有「在库 / 借出 / 维修中 / 已报废」四种状态，合法流转写死在代码里。已报废的设备不可能再被借出，借出中的设备不可能被重复借用。
2. **借还联动报修**：归还时若标记为损坏，系统自动把设备置为「维修中」并生成维修工单，不需要再人工补一张报修单。耗材领用超过库存会被直接拦截，低于安全阈值自动进入预警列表。

## 四、技术说明

- 语言：Java 24（无第三方依赖，标准库实现）
- 结构：表现层 / 门面控制层 / 业务逻辑层 / 数据访问层 / 领域模型层
- 数据：内存仓储（`InMemoryDatabase`），重启后数据清空，属于课程演示版本
- 构建运行：见下方脚本

```powershell
.\build.ps1       # 编译
.\run-tests.ps1   # 运行 40 项自动化测试
.\run-demo.ps1    # 端到端演示
```
