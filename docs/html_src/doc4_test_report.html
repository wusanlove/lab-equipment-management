2. 测试策略与方法

2.1 等价类划分与边界值分析法

针对系统中的数值计算、日期比较与库存阈值判断，重点采用有效/无效等价类划分与边界值分析法（Boundary Value Analysis）：

（1）日期与数值边界验证：测试设备质保到期日早于购置日期（TC12）、借用应还日期早于借出日期、申购数量为 0 或负数以及预计单价为负数（TC19）等无效等价类，验证系统是否精准抛出 IllegalArgumentException。

（2）耗材低水位安全阈值精确边界验证：针对预警判定式 currentStock < safetyThreshold（设 safetyThreshold = 10），专门设计边界值三点测试（TC39）：当库存扣减至 10（恰好等于阈值上边界）时，验证 isLowStock() == false 不误报；当继续领用 1 瓶使库存降至 9（紧邻阈值下边界）时，验证立即触发低库存预警；当领用数量超过当前实际库存（TC38）时，验证防超领异常拦截。

（3）空仓库完好率零除边界验证：测试新建空数据库（设备总数 total == 0）时的盘点统计（TC36），验证完好率默认返回 100.0% 且无除零异常。

2.2 有限状态机路径与非法转移覆盖测试

围绕设备四态状态机（IN_STOCK、BORROWED、MAINTENANCE、SCRAPPED），同时设计合法迁移路径覆盖（入库$\rightarrow$借出$\rightarrow$完好归还、借出$\rightarrow$受损归还自动转修$\rightarrow$维修完工恢复在库、在库/维修$\rightarrow$报废）与非法状态跃迁反例测试：验证已报废终态设备严禁逆向流转至在库、借出或维修（TC15、TC25），验证处于已借出状态的设备严禁被第二人重复借出（TC24）或未归还直接报废（TC16）。

2.3 RBAC 角色越权与防自锁安全测试

针对四类系统角色，设计越权攻击测试矩阵：验证学生越权登记设备台账（TC10）、学生越权提交设备采购申请（TC18）、学生或普通指导教师越权批准固定资产报废（TC34）、非系统管理员尝试禁用他人账号（TC07）均被 AuthService.requireRole() 拦截并抛出 SecurityException；同时验证系统管理员尝试禁用自身账号时被防自锁机制拦截（TC06）。测试策略与七大模块覆盖映射如表 2-1 所示。

3.3 自动化单元测试断言代码设计

以下截取 src/test/java/cn/edu/ctgu/labms/AllTests.java 中针对“设备受损归还自动转修并生成维修单（TC27）”与“低库存阈值边界校验（TC39）”的核心白盒测试断言代码：

// TC27: 验证借用设备受损归还(conditionOk=false)自动流转至MAINTENANCE并创建维修单

private static void testReturnEquipmentDamagedAutoTriggersMaintenance() {

    LabSystemFacade sys = new LabSystemFacade();

    User mgr = sys.registerUser("mgr", "Mgr@1", "实验员", Role.LAB_MANAGER, "中心");

    User stu = sys.registerUser("stu", "Stu@1", "学生", Role.STUDENT, "学院");

    Equipment eq = sys.registerEquipment(mgr.getId(), "EQ-RET2", "机械臂实训台", "DOBOT-Magician",

            "机器人设备", "越疆", 12000.0, LocalDate.of(2025, 1, 1), LocalDate.of(2028, 1, 1), "B202");

    BorrowRecord br = sys.borrowEquipment("EQ-RET2", stu.getId(), mgr.getId(), "视觉抓取实验",

            LocalDate.of(2026, 4, 1), LocalDate.of(2026, 4, 10));

    sys.returnEquipment(br.getRecordId(), mgr.getId(), LocalDate.of(2026, 4, 7), false, "末端舵机齿轮卡死");

    assertTrue(br.isReturned(), "借用记录应标记为已归还");

    assertEquals(Boolean.FALSE, br.getReturnConditionOk(), "归还完好标志应为false");

    assertEquals(EquipmentStatus.MAINTENANCE, eq.getStatus(), "受损归还后设备必须自动转入MAINTENANCE");

    List<MaintenanceScrapRecord> tickets = sys.getMaintenanceScrapService().findAllRecords();

    assertEquals(1, tickets.size(), "受损归还必须自动生成1张维修工单");

    assertEquals(OrderStatus.PENDING, tickets.get(0).getStatus(), "新生成维修工单状态应为PENDING");

}
